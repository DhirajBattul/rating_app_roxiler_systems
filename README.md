Rating_app for my application at Roxiler Systems

Tech stack:


- **Backend:** Node.js + Express
- **Database:** PostgreSQL (via Sequelize ORM)
- **Frontend:** React 
- **Auth:** JWT 


how to run: 

1. CREATE DATABASE store_rating_db;
   
2. Backend:
 cd backend
 npm install
 cp .env.example .env
seed admin: node seedAdmin.js
npm run dev

3.Frontend:
cd frontend
npm install
npm start
